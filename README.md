# ✈️ Sistema de Voo

Sistema de voo para SA-MP, reescrito e otimizado.

---

## 📌 Funções

### `Fly_Start(playerid)`
Inicia o modo de voo.

### `Fly_Stop(playerid)`
Encerra o modo de voo.

---

## ⚙️ Configuração

```pawn
#define FLY_SHOW_TUTORIAL <modo>
#define FLY_IS_MOBILE (0 - não | 1 - sim)
#include <fly>
```

### Modos disponíveis

- `0` — Desativa o tutorial  
- `1` — Tutorial via chat  
- `2` — Tutorial via GameText
